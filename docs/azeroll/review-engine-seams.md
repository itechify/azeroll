## Must-fix

1. **Release mode-owned asset handles at world teardown.** `crates/benilla-world/src/terrain_stream/partitions.rs:54`, `:440`, `:642`; `terrain_stream/retirement.rs:54`; `terrain_stream.rs:1117`. `WmoPartitions.ready` retains strong handles to complete derived city models indefinitely. `WmoParts` also retains both original and derived models, and `WmoPlacements` retains originals. `release_world` clears model forms and streamed products but none of these resources. Their snapshot publishers are gated by `world_is_live`, so logout never publishes an empty snapshot. Cross-map streaming clears snapshots later but still never evicts the derived-model cache. This keeps large city geometry and referenced assets alive beyond world lifetime, especially undesirable on wasm. **Fix:** add an ungated teardown cleanup for snapshots/instance mappings and evict derived assets on world/map release (or explicitly bound and scope the cache). Preserve authored plans and run tombstones separately so ordinary stream-out/in and Ready restoration still work. Verify logout, map change and re-entry with asset/handle counts.

## Should-fix

2. **[Fixed 2026-11-03, lead] Guard disabled cutout before fragment arithmetic.** `crates/benilla-assets/src/shaders/wow_model.wgsl:425`, `:440`; `crates/benilla-world/src/shaders/static_gx.wgsl:186`, `:201`. Removing the foliage-bit gate makes every retained fragment and every non-UI entity fragment call the cutout helper. Eye-space transformation, distance/sqrt, smoothstep and noise are expressed before the enable test. Zero defaults preserve the discard result but do not establish the requested zero-work disabled path; backend optimization is unverified. **Fix:** put a uniform `if (wow_light.cutout_limits.z <= 0.5) { return false; }` before all helper math, in both shaders. If exact stock shader cost is a requirement, use a default-off shader specialization. Compare disabled native/WebGPU output and GPU timing.

3. **Whole and partial retirement can double-count restoration.** `crates/benilla-world/src/terrain_stream/partitions.rs:526`, `:541`; `terrain_stream/retirement.rs:75`. Reproducer: retire a part, then retire its whole placement, then send `RestoreWmos`. Partial restoration accepts the suppressed placement because it remains `spawned`, sets it unspawned and adds one pending spawn. Whole restoration adds another pending spawn for the same placement. Only one root spawn can discharge that count, leaving perpetual pending work/loading bookkeeping. Current authored city/building targets are distinct, but the exported generic APIs do not enforce that restriction. **Fix:** let whole restoration exclusively rebuild suppressed placements, and reject part retirement of suppressed roots. Add a combined part/whole/restore lifecycle test.

4. **Reveal tests a downward column, not containment.** `crates/benilla-world/src/wmo_portal/mod.rs:416`. `column_in_collision_bounds(..., false)` checks XY containment and only the *lower* Z bound. A reveal point arbitrarily far above a building therefore reveals all its rooms, contrary to D8's containing-building contract. **Fix:** use a dedicated full XYZ bounds test (with an intentional small tolerance if needed); retain the existing half-space helper for actual down-rays. Check points below, inside and above a building and vertically overlapping WMOs.

5. **Snapshot publication repeatedly scans all part products.** `crates/benilla-world/src/terrain_stream/partitions.rs:623`, `:633`. Every live frame with a plan rebuilds vectors and scans all `PieceProduct` entities once per part, including non-collider mesh/light products. With 37 city pieces this is O(parts × products) even after residency settles. No disabled-plan scan occurs, but this is avoidable steady-state city CPU/allocation work. **Fix:** index collider/pending-collider products by placement/group in one pass and publish only on relevant entity/collider/residency changes. Keep rendering/residency ownership in the existing streamer.

## Nits / mergeability

6. **Separate authored decomposition tooling from lifecycle hooks.** `crates/benilla-world/src/terrain_stream/partitions.rs:164`, `:456`. The new module is 867 lines including tests; together with the expanded spawn driver this is substantially larger than D9's small seams. Triangle selection, foundation synthesis and TOML audit output make future engine merges harder. **Suggested fix:** consider moving pure recipe-driven model preparation/audit into mode code, while keeping generic prepared-model selection, product ownership, retirement and streaming in the engine. This preserves D27's single streaming owner; do not introduce a second city streamer.
